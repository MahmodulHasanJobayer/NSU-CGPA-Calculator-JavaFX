# NSU-CGPA-Calculator-JavaFX

A simple desktop-based CGPA Calculator developed using Java and JavaFX for North South University (NSU) students. This application enables users to select courses, assign credits and grades, calculate their CGPA, and automatically save the results in a text file for future reference.

## Features
User-friendly graphical interface built with JavaFX</br>
Course selection from a predefined NSU course list</br>
Credit and grade input using dropdown menus</br>
Automatic CGPA calculation based on selected courses</br>
Student information storage in a text file (StudentInfo.txt)</br>
Instant display of calculated results

## Technologies Used
Java</br>
JavaFX</br>
File Handling (FileReader & FileWriter)</br>
Event-Driven Programming

## How It Works
Enter student name and ID.</br>
Select up to five courses.</br>
Assign corresponding course credits.</br>
Select achieved grades.</br>
Click Calculate CGPA.</br>
The application calculates the CGPA and saves all information to StudentInfo.txt.
